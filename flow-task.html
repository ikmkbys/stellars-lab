FLOW TASK

やることを覚えておく仕事を、頭から下ろすためのアプリ。

Why

「覚えておくこと」がいちばん疲れる

やることが5個あるとき、しんどいのは5個こなすことではなく、 5個あると覚え続けていることのほうでした。 風呂に入っていても、寝る前でも、頭のどこかがそれを握りしめている。

GTD という考え方に、気になっていることは全部いったん外に書き出す、という原則があります。 理屈は知っていたのに続かなかったのは、書き出す場所がいつも遠かったからです。 アプリを開いて、プロジェクトを選んで、期限を決めて……その手間を思い浮かべた時点で、 結局そのまま頭の中に置きっぱなしにしていました。

だから FLOW TASK は「放り込む」を一番手前に置いています。 分類も期限も後回しでよくて、まず外に出す。整えるのはあとから、気が向いたときで構いません。

Concept

管理者ではなく、友達でありたい

タスク管理アプリはしばしば、達成できなかった量を数字で突きつけてきます。 赤いバッジ、未達成の連なり、途切れた連続記録。 使うほど責められている気持ちになって、そっとアンインストールした経験が何度かあります。

なので FLOW TASK では、機能を足すか迷ったときの基準を 「友達ならどう言うか」に置いています。 友達は「今日も3件残ってるよ」とは言いません。 たまっているものがあれば、そっと目に入る場所に置いておくだけ。やるかどうかは本人が決めます。

実際に、しばらく手つかずのタスクを見直させる画面を作ったものの、 使ってみて「強制されている感じ」が強く、あとから引っ込めました。 いまは一覧の中に小さな印が灯るだけです。気づけばそれでいいし、気づかなくてもいい。

Flow

一日の流れ

  • 1. 放り込む思いついたら Inbox へ。分類も日付も、この時点では決めなくて構いません。
  • 2. 選ぶInbox を眺めて、今日やるものだけを Today へ。残りは「いつか」に置いておけます。
  • 3. 進めるスワイプで完了、ドラッグで並べ替え。終えるとささやかな紙吹雪が出ます。
  • 4. 翌朝に戻る手をつけなかった Today は翌朝そっと Inbox に戻り、また選び直しになります。

Features

そのほかの機能

  • マトリクスモード緊急度と重要度の4象限で並べ替えて、優先順位を見直せます。
  • 週次レポート1週間の動きをメールで受け取れます。振り返りのきっかけ用です。
  • カレンダー連携タスクを Google カレンダーの予定として登録できます。
  • 日本語 / 英語UI を切り替えられます。ダークモードにも対応。
  • PWAホーム画面に追加すればアプリのように起動します。ブラウザからそのまま使えます。
Todo を紙に書く人へ。 今日やることは紙の手帳に手書きし、それ以外の「いつかやるかもしれないこと」だけを FLOW TASK に預ける、という使い方をしている人がいます。 紙に書き写した時点でアプリ側は完了にしてしまってよくて、アプリは預かり箱に徹します。 手書きの気持ちよさを手放さずに、忘れる不安だけを外に出せます。

FAQ

よくある質問

料金はかかりますか？

現在は無料で使えます。

Android や iPhone のアプリはありますか？

ブラウザで動く PWA として公開しています。ホーム画面に追加すればアプリのように使えます。Android 版のストア公開は準備中です。

期限を決めないと使えませんか？

いいえ。期限なしのまま置いておけます。日付を決めるのは、決めたくなったときで大丈夫です。
