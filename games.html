それぞれのゲームについて

PIXEL RUNNER

走り続けるキャラクターを、ジャンプだけで操作する横スクロールゲームです。 操作はスペースキー（またはタップ）ひとつ。障害物を避けるほど速度が上がっていきます。

最初はもっと複雑な操作を考えていたのですが、試していくうちに全部削りました。 ボタンが一つしかないと、失敗したときに言い訳ができません。 「今の押すのが早かった」と自分で分かる。その素直さが気に入って、この形で止めています。

操作：スペース / タップでジャンプ

2048 STELLAR GRID

同じ数字のタイルを重ねて大きくしていく、よく知られたルールのスライドパズルです。 矢印キーかスワイプで盤面全体を動かします。2048 のタイルを作るのが一応の目標ですが、 その先も続けられます。

ルールは既存のものをなぞっていて、変えたのは見た目だけです。 暗い宇宙の配色にして、タイルが合わさるときの光り方を調整しました。 自分が遊ぶときの気分に合わせた、いわば模様替えです。

操作：矢印キー / スワイプ

CODE BREAKER

画面の上から降ってくる単語を、キーボードで打ち込んで撃ち落とすタイピングゲームです。 下の危険ラインまで到達される前に打ち切ります。進むほど速度と単語数が増えます。

タイピングゲームは昔からありますが、作ってみると難易度の調整がとても難しいことが分かりました。 速すぎると諦められ、遅すぎると退屈になる。 いまの設定は、自分がぎりぎり手が追いつかなくなる速度を基準にしています。

操作：キーボード
