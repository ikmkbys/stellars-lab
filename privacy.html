プライバシーポリシー

最終更新日：2026年8月14日

Stellars Lab（以下「当スタジオ」）は、ウェブサイト stellars-lab.com および当スタジオが提供する各プロダクトにおける情報の取り扱いについて、以下のとおりプライバシーポリシーを定めます。

第1条（適用範囲）

本ポリシーは、当スタジオが提供する以下のものに適用されます。

  • 本ウェブサイト（stellars-lab.com およびそのサブドメイン）
  • ツール：SizeKit・FLOW TASK・FLOW YOTEI・FLOW KAKEI・FLOW BASHO・HENSAI・Notipop
  • アプリ：Polaris
  • ビジュアライザ：ISS 3D・Solar System 3D・Near Stars
  • ゲーム：STELLAR ROGUE・PIXEL RUNNER・2048 STELLAR GRID・CODE BREAKER

プロダクトごとに取り扱う情報は大きく異なります。以下では、その違いが分かるように記載します。

第2条（取得する情報）

【本ウェブサイト】

  • アクセスに関する情報（閲覧されたページ、リファラー、おおまかな地域、ブラウザの種類など。個人を特定する情報は含みません）
  • 広告配信にともなって取得される情報（第4条に記載）

【端末内で完結し、当スタジオがデータを受け取らないもの】
SizeKit・HENSAI・Solar System 3D・Near Stars・PIXEL RUNNER・2048 STELLAR GRID・CODE BREAKER

  • これらは処理をすべてブラウザ内で行います。SizeKit で扱う画像、HENSAI に入力する借入情報などが当スタジオのサーバーへ送信されることはありません。
  • 設定や入力内容は、必要に応じてブラウザのローカルストレージに保存されます。

【ISS 3D】

  • 上空通過予測の機能を利用した場合にのみ、ブラウザを通じて位置情報を取得します（ブラウザ上で許可を求めます）。
  • 取得した位置情報は通過時刻の計算にその場で使用するだけで、当スタジオのサーバーや外部サービスへ送信・保存することはありません。

【Notipop（Chrome拡張）】

  • ユーザーが手動で選択したテキスト・ページタイトル・URL（メモとして送信する際のみ）
  • Notion API アクセストークン（設定画面で入力したもの。ブラウザのローカルストレージに保存）
  • 保存先として指定された Notion データベース ID

【FLOW TASK・FLOW KAKEI】

  • Google アカウント情報（Google Sign-In 経由。表示名・メールアドレス・UID）
  • ユーザーが入力したタスク、支出金額、カテゴリ、メモなどのデータ
  • アプリ設定（テーマ・言語・通知の設定など）

【FLOW YOTEI・FLOW BASHO】

  • イベント名、候補日または候補地、回答者が入力した名前と回答内容
  • 通知先として入力されたメールアドレス（FLOW YOTEI で通知を設定した場合）
  • ログインした場合は Google アカウント情報。ログインせずに作成・回答することもできます。
  • Google カレンダーの空き時間（FLOW YOTEI で連携を許可した場合のみ。予定の内容は取得しません）

【Polaris】

  • Google アカウント情報（表示名・メールアドレス・UID）
  • ユーザーが入力した目標・中期目標・アクションのテキスト
  • アプリ設定（テーマ・言語・AIトーン）
  • 決済情報（Stripe を介して処理され、当スタジオはカード情報を保持しません）

【STELLAR ROGUE】

  • ランキングに登録した場合のみ、入力された名前・スコア・到達ウェーブ。匿名認証による識別子とともに保存されます。
  • 登録せずに遊ぶこともできます。その場合は何も送信されません。

第3条（利用目的）

取得した情報は以下の目的にのみ使用します。

  • 各プロダクトの機能提供
  • AIによる目標ロードマップ・月次レポートの生成（Polaris のみ）
  • 決済処理および有料プランの管理（Polaris のみ）
  • 日程・場所の調整に関する通知メールの送信（FLOW YOTEI のみ）
  • 本ウェブサイトにおける広告の配信
  • アクセス状況の把握とサービス改善、障害対応

第4条（広告の配信について）

本ウェブサイトでは、第三者配信の広告サービスである Google AdSense を利用しています。

  • Google を含む第三者配信事業者は、Cookie を使用して、ユーザーの過去のアクセス情報にもとづく広告を表示することがあります。
  • Google が広告 Cookie を使用することにより、当スタジオや他のサイトへのアクセス情報にもとづいて広告を配信することがあります。
  • ユーザーは Google 広告設定 でパーソナライズ広告を無効にできます。
  • 第三者配信事業者による Cookie の使用を停止する方法は www.aboutads.info に説明されています。
  • 詳しくは 広告 – ポリシーと規約 – Google をご確認ください。

広告は本ウェブサイトに掲載されるものであり、各プロダクトで扱うデータ（画像・タスク・借入情報など）が広告配信に利用されることはありません。

第5条（アクセス解析について）

本ウェブサイトおよび各プロダクトでは、利用状況を把握するために Vercel Analytics を利用しています。取得される情報は閲覧されたページやおおまかな地域などに限られ、個人を特定するものではありません。

第6条（Cookie の使用）

当スタジオは以下の目的で Cookie またはそれに類する技術を使用します。

  • 広告の配信（第4条に記載）
  • ログイン状態の維持（Polaris・FLOW シリーズにおける Firebase Authentication のセッション管理）
  • 言語やテーマなどの設定の保持

ブラウザの設定により Cookie を無効にできますが、その場合ログインを必要とする機能が利用できなくなることがあります。

第7条（第三者提供）

当スタジオは、以下の場合を除き、ユーザーの個人情報を第三者に提供しません。

  • ユーザーの事前同意がある場合
  • 法令に基づく場合

第8条（利用している外部サービス）

各プロダクトは以下の外部サービスを利用しており、それぞれのプライバシーポリシーが適用されます。

  • Google AdSense（本ウェブサイト）— Google プライバシーポリシー
  • Firebase / Google Cloud（Polaris・FLOW シリーズ・STELLAR ROGUE）— Google プライバシーポリシー
  • Google カレンダー API（FLOW YOTEI。空き時間の読み取りのみ）— Google プライバシーポリシー
  • Notion API（Notipop・Polaris）— Notion プライバシーポリシー
  • Anthropic Claude API（Polaris）— Anthropic プライバシーポリシー（ユーザーデータは AI 学習に使用されません）
  • Stripe（Polaris）— Stripe プライバシーポリシー
  • Resend（FLOW YOTEI のメール送信）— Resend プライバシーポリシー
  • Where the ISS at? API・BigDataCloud（ISS 3D。国際宇宙ステーションの位置と、その直下点の地名の取得に使用します。ユーザーの位置情報は送信しません）
  • Vercel（ホスティングおよびアクセス解析）— Vercel プライバシーポリシー

第9条（データの保存場所）

端末内で完結するプロダクト：SizeKit・HENSAI・ビジュアライザ・ゲーム（STELLAR ROGUE のランキング登録を除く）で扱うデータは、ユーザーのブラウザ内にのみ保存されます。

Notipop：Notion API アクセストークン・データベース ID はブラウザ内ローカルストレージにのみ保存され、当スタジオのサーバーには送信・保存されません。

Polaris・FLOW シリーズ・STELLAR ROGUE：入力されたデータは Google Firestore に保存されます。データセンターの所在地は米国または日本です。

第10条（データの削除）

端末内で完結するプロダクト：ブラウザの閲覧データを削除することで消去できます。

Notipop：拡張機能をアンインストールすると、ローカルストレージに保存されたデータは削除されます。

Polaris・FLOW シリーズ：アプリ内の設定画面から、保存されたすべてのデータおよびアカウントを削除できます。

そのほか削除をご希望の場合は、第13条の連絡先までご連絡ください。

第11条（未成年者の利用）

当プロダクトは13歳未満の方の利用を想定していません。13歳未満の方の個人情報を意図せず取得した場合、速やかに削除します。

第12条（本ポリシーの変更）

本ポリシーは必要に応じて変更されることがあります。変更後のポリシーは本ページへの掲載をもって効力を生じます。重要な変更がある場合は各プロダクト内でお知らせします。
